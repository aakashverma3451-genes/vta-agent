An antiviral triage agent whose validation deflates its own inflation

VTA-Agent — autonomous, leakage-aware structure-based virtual screening, orchestrated with LangGraph.

vta-agent/figure-set · all values from committed benchmark artifacts · 276 hermetic tests

Structure-based virtual screening is easy to fool yourself with — inflated control panels, leaky decoys, size-biased scores, invalid significance tests. VTA-Agent is built so every enrichment claim must survive the checks a skeptical reviewer would apply before the claim is made.

On the only powered benchmark (SARS-CoV-2 Mpro, real measured inactives), AutoDock Vina does not beat a trivial 2-D-similarity baseline (BEDROC 0.68 vs 0.92). On a powered fair-arena test — 1,193 activity cliffs — Vina is below chance (0.42), and a learned RF-Score rescorer fails identically (0.39); a trivial ligand QSAR wins (0.67).

A component ablation shows the gains are routing-type-dependent: the router fixes out-of-domain targets, the verification gate fixes in-domain targets that lose to 2-D, and neither layer alone suffices. The workflow — not the docking — is the contribution. Outputs are ranked, uncertainty-bearing hypotheses, never efficacy claims.

InterpretationAs in HemaGuide's routing ablation, no single component is sufficient across case types. The router answers "should we dock this at all?"; the gate answers "may we claim a win?" Figure 3The fair-arena test: docking has no ranking skill on activity cliffs

acliff-pair ranking accuracy, 1,193 pairs (median, 95% CI)

bthe ordering flips between the two arenas

Fig. 3 | Activity-cliff benchmark (COVID-Moonshot Mpro). Cliffs are analog pairs near-identical in 2-D but with a large potency gap, so ligand-similarity is weakest and structure-based skill can show. 345 compounds were docked to lift the pool from 17 → 1,193 pairs (powered). a, Vina (0.42) and a learned RF-Score (0.39) are both significantly below chance — anti-correlated with potency, most likely Vina's size bias; a trivial 2-D-kNN QSAR wins (0.67; paired RF−Vina −0.03, indistinguishable). b, The ordering that holds on the analog-clustered enrichment set reverses in the fair arena.

InterpretationEven where docking should have the advantage it does not, and a learned rescorer does not rescue it — a powered fair-arena negative. Scope: RF-Score is target-specific and coarse; it does not settle whether a GPU-scale GNINA CNN would transfer.

InterpretationThe headline number is a negative, reported as-is: docking does not beat memorizing 2-D chemistry. Most screening papers never run that baseline. The ladder is the scientific contribution — a pipeline built to deflate its own inflation.

Reproducibility

276

hermetic tests; every external call behind an injectable seam with a committed cache — degrade honestly, never fabricate.

Statistics

Bootstrap 95% CIs (10,000×); paired bootstrap difference test (never CI-overlap); Holm–Bonferroni; binding modes never pooled.

Baselines

ECFP4 2-D similarity (leave-one-out) + random null on the identical split — the trivial floor any structure-based claim must clear.

Honest scope

Outputs are ranked, uncertainty-bearing hypotheses — never clinical, efficacy, or safety claims. No wet-lab validation.
