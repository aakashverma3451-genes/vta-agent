The differentiator

Most screening tools inflate. This one deflates itself.

Every hard test we added lowered our own apparent performance — and the pipeline reported it, against itself. That ladder is the science.

① A 9-ligand control panel looked great

3 / 4 known inhibitors landed in the top 5. Textbook "it works!" moment.

② …until we added property-matched decoys

Recovery collapsed to 1 / 4. The inflated control panel did not survive real decoys.

③ …then we put confidence intervals on everything

Bootstrap 95% CIs were ≈ [0, 1] — statistically underpowered, not a claim.

④ …so we built a properly powered target

SARS-CoV-2 Mpro: 50 real actives vs 50 experimentally-measured inactives (COVID Moonshot).

⑤ …and tested it against a trivial baseline

Docking did not beat 2D-similarity memorization. Structure-based enrichment: not demonstrated.

⑥ …and proved that's honest, not broken

Vina redocks the native ligand to 1.65 Å — so it's a ranking limit, not a pose-search failure.
The headline result

On our powered benchmark, docking loses to a 2D lookup.

A method that can't beat 2D-similarity memorization hasn't shown structure-based skill (Wallach & Heifets 2018). We ran the check most papers skip — and reported the answer.

A publishable side-effect

Why "validating" a nucleotide antiviral is usually a mirage

The nucleotide meta-finding

Drugs like remdesivir & sofosbuvir act as triphosphates — so charged and polar that no scaffold-distinct, property-matched decoy exists for them. Matched-decoy validation simply cannot build the control set.

Corollary warning to the field: a pipeline that appears to "validate" a nucleotide antiviral is almost always docking the parent prodrug, not the active species.

We proved it isn't a species artifact

Docking the real triphosphate vs the parent into the HCV NS5B active site (with catalytic Mg²⁺) changed ΔG by only −0.10 kcal/mol — sofosbuvir's parent even out-scored its own triphosphate.

So the poor recovery is a genuine scoring limitation, not "we docked the wrong molecule."

Under the hood

One genome in, an auditable report out

A LangGraph state machine of typed nodes. Real scientific tools when present; a labelled, provenance-bearing fallback when not — never a silent fake, never a crash.

🧬 Real structure

Experimental PDB first, then ESMFold → AlphaFold DB → Boltz-2 → an honest refusal. Never a guess passed off as truth.

🎯 Real docking

AutoDock Vina 1.2.5; receptor prep via Meeko with an OpenBabel fallback. Binding modes (covalent vs non-covalent) never pooled.

📊 Real statistics

Every metric a median + 95% CI. Significance by paired bootstrap + Holm–Bonferroni — the CI-overlap shortcut was purged from the codebase.

⚖️ Gated ranking

A weight only changes if a paired test justifies it. We demoted our own ligand-efficiency term to ΔG when the data didn't support it.

🔬 Trivial baselines

Random + 2D-similarity, on the identical split — so "it works" has to beat memorization before we believe it.

🧾 Provenance

Tool versions, seeds, decoy sources, and a full audit trail on every run. A frozen, hash-stamped benchmark artifact.
